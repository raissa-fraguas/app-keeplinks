---

## 💡 Sobre o Projeto

O **KeepLinks** nasceu da necessidade de organizar o caos dos "links salvos" das redes sociais. Sabe aquele post incrível, tutorial ou thread que você salvou no Instagram, Twitter/X ou TikTok e nunca mais encontrou? Este app resolve isso. 

Ele permite que você guarde URLs de qualquer rede social e as organize em categorias personalizadas, transformando sua curadoria de conteúdo em um processo eficiente, visual e sempre acessível.

---

## ✨ Funcionalidades (Planejadas e em Desenvolvimento)

- 📥 **Salvamento Rápido**: Adicione links de qualquer rede social com facilidade.
- 🏷️ **Categorização Inteligente**: Organize seus links em pastas ou tags personalizadas (ex: "Estudos", "Design", "Receitas", "Inspiração").
- 🔍 **Busca e Filtragem**: Encontre qualquer link salvo em segundos.
- 🎨 **Interface Moderna**: UI limpa, responsiva e com animações suaves.
- 🤖 **Assistência com IA** *(Em breve)*: Sugestão automática de categorias e resumos do conteúdo do link (utilizando Google GenAI).

---

## 🛠️ Tecnologias Utilizadas

Este projeto é construído com uma stack moderna:

- **Runtime & Package Manager**: [Bun](https://bun.sh/)
- **Frontend**: [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Estilização**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Ícones**: [Lucide React](https://lucide.dev/)
- **Animações**: [Motion](https://motion.dev/)
- **IA (Experimental)**: [@google/genai](https://ai.google.dev/)
